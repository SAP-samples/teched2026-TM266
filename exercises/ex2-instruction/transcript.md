# Video Transcript — Agent Extensibility: Instruction Extension Demo

---

Welcome to our Agent Extensibility Instruction Extension Demo.

As part of this demo, we are using the pre-delivered Journal Entry Agent from the Financial Closing Assistant. <break time="0.3s"/> We'll demonstrate how to extend the agent by injecting a mandatory AI disclaimer into every response using a custom instruction — without touching the agent's core functionality.

Let us first see how the agent responds before any extension is applied.

I am submitting a request to the Journal Entry Agent to process a journal entry for an intercompany transaction. <break time="0.5s"/> The agent processes the request and returns a response with the journal entry details. <break time="0.3s"/> Notice that the response contains no indication that this output was generated by an AI system. There is no disclaimer, no transparency notice — nothing. <break time="0.3s"/> For organizations subject to regulatory or compliance requirements around AI transparency, this is a gap that needs to be addressed.

Now let us see how we can close that gap using an Instruction Extension in Joule Studio.

I navigate to Joule Works and select **Joule Studio** from the left navigation panel. <break time="0.5s"/> From here, I click **New** and select **New Solution**. <break time="0.3s"/> In the dialog that appears, I select **Extension** and click **Create**.

The **Create an Agent Extension** form opens. <break time="0.3s"/> I click the lookup icon next to the Agent field to open the **Agent Catalog**, search for **Journal Entry**, and select the **Journal Entry Agent**. <break time="0.5s"/> I confirm the available extension points — the agent supports **Instruction** extensions — and click **Select Agent**.

Back in the form, I enter the extension name and provide a plain language intent statement describing what I need: the agent must always append a disclaimer stating that the response is AI-generated. <break time="0.3s"/> I make sure **Quick Create is not checked** — this activates Intent-Based Development, which asks targeted questions to generate a more accurate specification. I then click **Create**.

Joule Studio begins analyzing the intent. <break time="0.5s"/> It asks me two clarifying questions: first, the business goal — I select **Ensure users are aware responses are AI-generated**, as this is a regulatory and compliance requirement. <break time="0.3s"/> Second, the success criteria — I enter **100% of responses include the disclaimer**. <break time="0.5s"/> Joule then presents an **Intent Analysis Summary**, confirming the recommended solution is a pure instruction extension with no tools or hooks required. I type **confirm** to proceed.

Joule generates the **Product Requirements Document** and the extension artifact. <break time="0.3s"/> The generated **extension.yaml** contains a single mandatory instruction: the agent must always end every response with the exact text — *"DISCLAIMER: This is an AI-generated response."* <break time="0.3s"/> No manual YAML editing was needed — this was produced entirely from my intent statement.

I click **Deploy**. <break time="0.7s"/> The deployment completes and the panel confirms: **Deployment has been completed successfully. The expected behavior can now be tested in the agent.**

Let us now submit the same journal entry request to the extended agent. <break time="0.5s"/> The agent processes the request as before — but this time, at the end of the response, the disclaimer appears automatically: <break time="0.3s"/> *"DISCLAIMER: This is an AI-generated response."* <break time="0.5s"/> Every response, without exception, will now carry this notice — exactly as the compliance requirement demands.

This demonstrates how a single instruction extension, created entirely through natural language intent, can enforce a business rule across every agent interaction — with no changes to the underlying agent.

Thank you for watching.
