# Exercise 1 - Run the Standard Journal Entry Agent

In this exercise, we will run the pre-delivered Journal Entry Agent in SAP Joule Works and verify the result in SAP S/4HANA Cloud, Public Edition — before any extensions are applied.

### About the Journal Entry Agent

With the Journal Entry Agent, your finance team can significantly reduce the time and effort required to prepare and post journal entries — without compromising auditability or compliance. The agent automates data conversion and allows accountants to identify and resolve issues early, reducing rework, minimizing posting errors, and standardizing journal entry processing across the organization.

The solution generates upload-ready journal entry proposals directly from raw data files. It notifies users when proposals have been successfully generated and delivers them for review, management, and posting in the Manage Journal Entry Proposals app.

**Business value:**
- 70% reduction in time to curate manual journal entries
- 50% reduction in time to upload and validate manual journal entries
- Faster period-end close, giving teams more time for high-value activities

### Key Features

The Journal Entry Agent provides AI-assisted support for the creation of journal entries by generating accurate and compliant journal entry proposals. The agent includes these features:

- Automatically generates journal entry proposals based on requests initiated via the Joule chat window
- Processes spreadsheet-based input to derive complete journal entry proposals
- Supports policy upload and enforcement per company code
- Identifies opportunities for line item merging to reduce line count while preserving proposal structure
- Records and displays the processing steps that led to the proposed journal entries to ensure transparency
- Notifies users when journal entry proposals have been successfully generated and are ready for review
- Delivers generated proposals for review, management, and posting in the Manage Journal Entry Proposals app

### Manage Journal Entry Proposals App (F9263)

The Manage Journal Entry Proposals app enables the transition from manual journal entry creation to an automated, AI-assisted process. It supports efficient journal entry management based on proposals generated by the Journal Entry Agent. Using the app you can:

- Review journal entry proposals prepared by the Journal Entry Agent
- Post journal entries after reviewing the proposals
- Delete or change proposals
- View errors and warnings resulting from validation checks
- View the uploaded file that led to the proposal
- Use the **Generate Proposals** button to generate new journal entry proposals with the Journal Entry Agent

### How the agent works

You interact with the Journal Entry Agent through the Joule chat window. By submitting a request and uploading a data file, you instruct the agent to analyze the content and generate journal entry proposals based on the data in the file.

The agent creates proposals rather than final postings, allowing you to review, validate, and adjust the proposed journal entries before posting them in the Manage Journal Entry Proposals app.

The agent follows this process:

1. *(Optional)* Upload a **policy file** — the agent uses this to validate proposals against your company code's permitted G/L Account and Cost Center or WBS Element combinations.
2. **Submit a request** via the Joule chat window and attach a spreadsheet with your journal entry data.
3. The agent **generates proposals** — mapping columns, processing the data, and preparing the entries for review.
4. **Review and post** the proposals in the Manage Journal Entry Proposals app.

> **Note:** When you upload a data file, the content is processed by a large language model (LLM) to generate AI-assisted results.

### Spreadsheet Requirements

The Journal Entry Agent requires spreadsheet-based input. You must upload a Microsoft Excel file (.xlsx or .csv). A single uploaded spreadsheet can result in a maximum of 999 journal entry proposals.

The file does not need to follow a predefined template — the agent scans the spreadsheet and proposes a mapping between the file columns and the journal entry fields. The uploaded data must include values that can be mapped to the following mandatory fields:

- Journal Entry Date
- Posting Date
- Journal Entry Type
- Company Code
- Transaction Currency
- G/L Account
- Debit Amount
- Credit Amount

In this exercise, a pre-prepared data file is provided for you. You will use it together with a natural language prompt to trigger the agent.


   > **Note:** The exact URL will be provided by the instructor and is printed on the card at your desk.

2. Log in using the credentials provided by the instructor:

   | Field | Value |

   | User  | `TM266-XXX` *(where XXX is your participant number)* |
   | Password | *(as provided by the instructor)* |

<br>![](/exercises/ex1/images/ex1_1_01_login.png)

3. Once logged in, the Joule Works chat window opens.
   
<br>![](/exercises/ex1/images/ex1_1_02_joule_home.png)

4. In the chat window, enter the following prompt: **@Financial Closing Assistant Create Journal Entry Proposal from File**. By using @Financial Closing Assistant we are invoking the agent, and Create Journal Entry Proposal from File is the natural language prompt that tells the agent which action to execute.
   
 <br>![](/exercises/ex1/images/ex1_1_03_prompt_entry.png)
  
5. Download the sample file from GitHub (placeholder location), save it to your desktop. Open the file and replace the header text **TM266-xxx** with your participant ID — for example, TM266-001 — then verify your data matches the structure shown below before uploading.

<br>![](/exercises/ex1/images/ex1_1_04_agent_response2.png)

6. The agent responds by prompting for a file upload — **click Select your files or drag and drop your Excel (.xlsx, .xls) or CSV (.csv)** file containing the journal entry data (Company Code, Posting Date, GL Account columns) into the upload area and click **send**

<br>![](/exercises/ex1/images/ex1_1_04_agent_response1.png)

<br>![](/exercises/ex1/images/ex1_1_04_agent_response3.png)

7. Once you upload the file, the agent begins processing it — you will see the status for example "Resuming workflow with your additional input..." i the screenshot indicating the agent is reading your file and preparing the journal entry proposal.

<br>![](/exercises/ex1/images/ex1_1_04_agent_response4.png)

8. The agent has parsed your Excel file and intelligently mapped all 14 columns to the corresponding SAP fields — grouping them into Header, Item, Debit, and Credit mappings. Each mapping shows a Confidence score, indicating how certain the agent is about each column match (most are 90–100%). You have three options at this point:

    - Approve Mapping — confirms the mapping is correct and the agent proceeds to generate the journal entry proposal
    - Adjust Mapping — lets you correct or override any column mapping before proceeding
    - Reject Mapping — cancels the mapping entirely if something is fundamentally wrong

   For this exercise, click **Approve Mapping** to proceed.
  
<br>![](/exercises/ex1/images/ex1_1_04_agent_response5.png)
  
9. The Journal Entry Agent processes your request and generates a journal entry proposal. You will see the agent's response in the chat window with a summary of the proposed posting.

<br>![](/exercises/ex1/images/ex1_1_04_agent_response6.png)

8. Review the response. The agent confirms the proposal is ready for review in the Manage Journal Entry Proposals app.

   > **What to observe:** The agent processes the request and returns a proposal — no additional checks fire, no flags are raised, and no report is generated. This is the standard out-of-the-box behavior. You will compare this to the extended agent in Exercise 2.
