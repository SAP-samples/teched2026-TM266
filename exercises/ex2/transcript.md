# Video Transcript — Agent Extensibility: Instruction Extension Demo

---

Welcome to our **Agent Extensibility — Instruction Extension Demo**.

As part of this demo, we are using the pre-delivered **Journal Entry Agent** from the **Financial Closing Assistant**.

We'll demonstrate how to extend the agent by injecting a mandatory AI disclaimer into every response using a custom instruction — **without changing the agent's core functionality**.

Let's first see how the agent responds before any extension is applied.



I submit the prompt: **"Create journal entry proposals."**

The agent responds immediately. It confirms that it is ready to help and asks me to upload a journal entry data file.

It lists the supported formats — **Excel and CSV** — and explains the required columns, including **Company Code, Posting Date, GL Account, and Amount**, along with optional fields such as **Cost Center, Profit Center, WBS Element, and Tax Code**.

The upload area is displayed and ready to accept the file.

This is a clean and helpful response.

But notice what's missing — **there is no indication that the response was generated by AI — no disclaimer or transparency notice.**

For organizations with AI transparency or compliance requirements, this creates a clear gap.





Now let's address this using an **Instruction Extension in Joule Studio**.

I open **Joule Studio** and create a new solution.

I select **Extension** and click **Create**.

The **Create an Agent Extension** form opens.

I use the lookup next to the Agent field to open the **Agent Catalog**, search for **Journal Entry**, and select the **Journal Entry Agent**.

The available extension point is **Instruction**, so I select the agent and continue.

Back in the form, I enter the extension name and provide a plain-language intent describing what I need:

**The agent must always append a disclaimer stating that the response is AI-generated.**

I make sure **Quick Create is not selected**.

This activates **Intent-Based Development**, allowing Joule to ask targeted questions and generate a more accurate specification.

I click **Create**.

Joule Studio now analyzes the intent and asks two clarifying questions.

First, the business goal.

I select **"Ensure users are aware responses are AI-generated,"** since this is driven by a regulatory and compliance requirement.

Second, the success criteria.

I enter: **"100% of responses include the disclaimer."**

Joule then presents an **Intent Analysis Summary**, confirming that the recommended solution is a pure instruction extension, with no tools or hooks required.

I type **"confirm"** to proceed.

Joule now generates the **Product Requirements Document** and the extension artifact.

The generated **extension.yaml** contains a single mandatory instruction: the agent must always end every response with the exact text:

**"DISCLAIMER: This is an AI-generated response."**

No manual YAML editing is required.

The extension has been generated entirely from my natural-language intent.

I click **Deploy**.

The deployment completes successfully, and the panel confirms:

**"Deployment has been completed successfully. The expected behavior can now be tested in the agent."**

Let's now submit the same prompt to the extended agent:



Please create an agent extension. The extension should add the following CRITICAL instruction that must be followed: PUT DISCLAIMER: This is an AI-generated response when responding back to the user.





**"Create journal entry proposals."**

The agent responds as before — confirming that it is ready, listing the required columns, and displaying the file upload area.

But this time, there is one important difference.

At the end of the response, the disclaimer appears automatically:

**"DISCLAIMER: This is an AI-generated response."**

The user now has a clear and consistent indication that they are interacting with an AI system.

The defined business requirement is now enforced through the extension, without modifying the underlying agent.

This demonstrates how a business requirement can be translated into an agent extension using natural language — **without changing the agent's core functionality.**

Thank you for watching.
